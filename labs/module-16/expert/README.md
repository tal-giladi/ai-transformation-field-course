# Expert deliverables — Open Hands

What an experienced pro bono consultant produced in this engagement, one file per stage. Use them in
lesson 16.6 to compare with your own work, after you have written yours: reading them first turns the
engagement into copying. They are one good answer, not the only one; the rubric in the module project
says what any strong answer needs. All people and organizations are fictional.
