# Lumen SaaS — the cast

Nine people you can interview at Lumen SaaS and one of its customers. Each file has a roleplay prompt you paste
into a new LLM chat; the model plays that person. How it works, and how to get feedback afterwards:
[persona format](../../common/persona-format.md) and [coach prompt](../../common/coach-prompt.md).

Don't read a prompt before you interview the person: it says what they hide. If you would rather not
roleplay, read the pre-run transcript in [`transcripts/`](transcripts/) and note what the interviewer missed.
