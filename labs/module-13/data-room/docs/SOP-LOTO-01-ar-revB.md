# SOP-LOTO-01 · إجراء القفل والوسم (LOTO) لماكينات الحقن

- Document: SOP-LOTO-01
- Language: Arabic
- Revision: B (2019-02-03)
- Owner: —

## الخطوات

1. أبلغ رئيس الوردية.
2. أوقف الماكينة إيقافاً عادياً.
3. أطفئ المفتاح الرئيسي، اقفله بقفلك الشخصي وعلّق بطاقة باسمك.
4. أطفئ مضخة الهيدروليك.
5. حرّر ضغط الهواء المضغوط.
6. تجربة التشغيل: اضغط على "تشغيل" وتأكد أنه لا توجد أي حركة.
7. الآن يمكن فتح الواقي.
