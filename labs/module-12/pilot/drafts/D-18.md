**Question:** האם צד צריך להוכיח נזק כדי לגבות פיצוי מוסכם?

**Answer**

1. תובע לפי תניית פיצוי מוסכם אינו צריך להוכיח את נזקו בפועל. [FCR-2018-416 ¶5]
2. יש להוכיח נזק ממשי כלשהו לפני שנפסק פיצוי מוסכם. [ARM-2021-296 ¶2]
3. תובע לפי תניית פיצוי מוסכם אינו צריך להוכיח את נזקו בפועל. [FCR-2022-097 ¶9]
4. תניית פיצוי מוסכם עומדת בתוקפה אם בעת החתימה היה לה יחס סביר לנזק הצפוי. [ARM-2023-366 ¶2]
