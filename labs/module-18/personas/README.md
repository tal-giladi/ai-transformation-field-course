# Tzurim Academic College — the cast

Nine people you can talk to in and around Tzurim Academic College. Each file has a roleplay prompt you paste into a new LLM chat; the model plays that person. How it works, and how to get feedback afterwards: [persona format](../../common/persona-format.md) and [coach prompt](../../common/coach-prompt.md).

Don't read a prompt before you talk to the person: it says what they hide. If you would rather not roleplay, read the pre-run transcript in [`transcripts/`](transcripts/) and note what the interviewer missed. The transcripts were run by a competent consultant on a tight schedule; they are not a model of the right questions.

In the capstone nobody tells you whom to meet, in which order, or what to ask. The brief gives you the sponsor on Monday 8 February; the rest is your plan.
