# Tzurim Academic College — the expert's deliverable set

> [!CAUTION]
> Do not open anything in this folder until you have submitted your own deliverable set and scored it with the rubric in the capstone project. The capstone has no hints; this folder is the answer. Reading it first turns a three-week engagement into a reading exercise and wastes the one unseen engagement in the course.

This is how an experienced consultant ran the Tzurim engagement, from the first day to the handover. Every number computed from the data room is real and reproduces from the files; where a figure is a judgment or an illustration, it says so. The pilot's model results in `06` are an illustrative worked example, not a measurement: your run will differ.
