# Module 2 quiz — Discovery that finds the real work

Ten scenario questions on discovery inside an organization: mapping stakeholders before the first interview, running interviews that get the real work and the real definitions, observing a process and building a task inventory, measuring baselines from exports that disagree, profiling data for a named AI use, writing a readiness assessment with honest evidence labels, and writing a findings memo — including checking one an AI assistant drafted. Each question is a decision you would face at an organization like Harbor & Pine. The pass mark is 70% (7 of 10).
