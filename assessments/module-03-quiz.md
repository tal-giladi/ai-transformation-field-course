# Module 3 quiz — From findings to a funded portfolio

Ten scenario questions on turning discovery findings into a funded portfolio: building the opportunity map, deciding step by step between automation, generation, an agent and a person, screening candidates with a data gate, scoring under locked criteria, running the scoring workshop and the leadership alignment session, building an ROI model that survives finance, sequencing a roadmap by evidence, and writing the decision-ready case. Each question is a decision you would face at an organization like Harbor & Pine. The pass mark is 70% (7 of 10).
