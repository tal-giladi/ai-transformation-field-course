# Module 5 quiz — Building and testing a pilot

Ten scenario questions on taking one AI use case from an approved business case to a running, monitored pilot: writing the pilot charter with its rule of use and value measurement plan, building a test set from real data and labelling it, building the pilot with no code and with Python, evaluating it against today and a no-AI baseline, designing a human check that actually checks, releasing it through shadow mode and stages, and the logging, monitoring and change control that keep it honest after launch. Each question is a decision you would face at an organization like Harbor & Pine. The pass mark is 70% (7 of 10).
