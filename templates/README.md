# Templates

Every document you produce in the course starts from one of these templates. Each page says when to use it, how to fill it in, and shows a short filled example from Harbor & Pine, the warm-up organization. Copy them into your own practice kit and adapt them to each organization (lesson 18.5 shows how). Templates are added module by module.
