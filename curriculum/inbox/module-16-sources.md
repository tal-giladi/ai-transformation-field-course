## Changes to report for `references/laws-and-guidance.md`

- **PPA guidance on the DPO duty is final** (15 July 2026, per Arnon, Tadmor-Levy), not a draft as the reference list says.
- **Data Security Regulations, First Schedule item 2**: a database with medical information is at the basic level if it meets *one of* two conditions, one being no more than ten authorized users (PPA English translation and Hebrew "אחד מאלה"). Worth a line in the reference list because small organizations rely on it.
- **Social Workers Law, 5756-1996, §8** (professional confidentiality) could be added to the Israel table for engagements with welfare organizations.
- **Section 46 digital donation reporting** (from 1 January 2026) is relevant to any nonprofit engagement.
